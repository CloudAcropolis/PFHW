# PFHW

PFHW is a free hosting control panel, a cPanel alternative, developed by [Cloud Acropolis](https://cloudacropolis.com). We replaced our own cPanel with it in summer 2026 and have used it in production since.

## Download

https://cloudacropolis.com/managed-web-server#download (version 2.5.0, about 2.5 GB)

## Licence

PFHW is free to use and is not open source. Its terms are in the file `LICENSE` of the release.
The software of others inside the images keeps its own licences, listed in `docs/v2/LICENCES.md`.
That file also explains how to get the source code of the GPL, LGPL and AGPL programs.
Written offer for that source: info@cloudacropolis.com
